# Language Courses

> 🗣️ **Enrolment, not just a catalogue** — a Laravel platform where picking a course books a date, a teacher and a place in the register

**Language Courses** is a course enrolment platform. Visitors browse the offer, open a course to see its lessons and teacher, and add it to a basket with the date they want. Checking out turns the basket into enrolments — real rows against the user, each with a lesson date and a status — rather than an order that somebody has to type into a system afterwards.

Behind the public side sits an admin area with its own role check: courses, lessons, teachers, users and enrolments are all managed from there. The whole thing ships with a Docker setup, so it runs without installing PHP, Composer or MySQL on the host.

## 🎯 Key Features

- **A basket that produces enrolments** — checkout writes an `Enrollment` per course with the chosen lesson date and a status, and links it to the lessons through a pivot table. The basket itself lives in the session, so browsing does not require an account; finishing does.
- **A date chosen at the point of buying** — the course page offers the available dates, and the choice travels with the basket item all the way into the enrolment.
- **Roles enforced by middleware** — the admin area sits behind `IsAdmin`, not behind a hidden link; a signed-in ordinary user gets a 403, not a menu without the button.
- **An admin area that covers the whole model** — add and edit courses, attach lessons, register teachers, manage users, and correct enrolments after the fact.
- **Accounts with a profile** — avatar upload, name change and password change, each as its own route with its own validation.
- **Findable by search engines** — `sitemap.xml` and `robots.txt` are generated by a controller, so they follow the catalogue instead of going stale.
- **One-command Docker setup** — `.tools/docker` brings up PHP-FPM, nginx and MySQL, installs dependencies and runs the migrations.

## 🧩 The Model

```
User ──< Enrollment >── Lesson        (many-to-many through enrollment_lesson)
             │
           Course ──< Lesson
             │
          Teacher
```

An enrolment is the centre of the application. It belongs to a user, points at a course through its lessons, carries the date the student picked and moves through a status — which is why the admin can edit one without touching the catalogue.

`Role` is a table rather than a column, so a user can be promoted without a migration.

## 🚀 Getting Started

### With Docker (recommended)

```bash
git clone https://github.com/dawidolko/LanguageCourses-Project-Laravel.git
cd LanguageCourses-Project-Laravel/.tools/docker
docker compose up -d --build
```

The container installs Composer and npm dependencies, generates the application key and runs the migrations on first boot.

### Without Docker

**Prerequisites:** PHP 8.2 with Composer, Node.js 18, MySQL 8.

```bash
git clone https://github.com/dawidolko/LanguageCourses-Project-Laravel.git
cd LanguageCourses-Project-Laravel

composer install
npm install && npm run build

cp .env.example .env
php artisan key:generate
```

Set the database in `.env`, then:

```bash
php artisan migrate --seed
php artisan serve       # http://127.0.0.1:8000
```
